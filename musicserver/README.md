# Diner Music Server

Sonos Era 100 über QR-Codes und den lokalen Diner-Musikserver steuern.

Aktueller für die Repository-Anbindung vorbereiteter Stand: **1.3.1**. Die freigegebene ZIP-Datei und der Quellcode müssen noch als Release bzw. unter diesem Ordner veröffentlicht werden. **Nicht** allein wegen dieser README-Datei davon ausgehen, dass ein GitHub-Update verfügbar ist.

Updatekanal: Release-Tags `music-v<version>`, zum Beispiel `music-v1.3.1`. Zu jedem ZIP gehört eine SHA-256-Datei.

Nächste geplante Erweiterung: URL-Audiostreams und Kategorien.
